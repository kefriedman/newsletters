This Week in AI

This week's updates lean heavily toward infrastructure and institutional momentum rather than flashy model wars. Google DeepMind pushed forward on both multimodal efficiency and applied science tooling, while Anthropic made significant moves on the policy, funding, and public-sector front. For practitioners, the key takeaway is that AI is increasingly being built into research and government workflows—not just chat interfaces.

Google DeepMind released an update to its Omni Flash line, focused on handling longer video clips at lower cost and latency. For developers building multimodal apps—especially those processing video content at scale—this is a meaningful efficiency upgrade that could reduce inference costs without sacrificing quality. Worth testing if you're currently bottlenecked on clip length or cost-per-request.

Google Antigravity Powers Agentic Drug Discovery

DeepMind detailed how its Antigravity platform, combined with new Cheminformatics Skills, enables agentic workflows for compound search and molecule design—including proposing novel rigidified macrocycles. This is a strong example of agents moving beyond text tasks into specialized scientific domains, and it's a signal that domain-specific "skills" layered onto agent frameworks are becoming the pattern to watch.

Research Worth Knowing

Memory That Forgets Smartly Beats Memory That Remembers Everything

Researchers pitted two approaches to conversational AI memory head-to-head: classic retrieval-augmented generation (search the full transcript) versus compacting each turn into atomic facts and searching those instead. Using a rigorous paired evaluation on nearly 2,000 questions, they found meaningful differences in which approach wins depending on question type—useful signal if you're deciding how to architect long-term memory for chatbots or agents.

Stop Making LLMs Re-Solve Problems They've Already Solved

This paper introduces "agentic reasoning caching"—once an LLM works through a task's logic, the solution can be reapplied to similar future tasks cheaply, via CPU execution, with minimal LLM involvement. This could significantly cut inference costs for agentic workflows that handle repetitive task patterns at scale.

Your AI Coding Assistant's Instructions Are Quietly Rotting

Coding agents like Claude Code rely on instruction files (AGENTS.md, CLAUDE.md) that are read every session—but these files drift out of sync with the actual codebase, creating a real but underappreciated "documentation debt" that taxes every subsequent agent interaction. If you're deploying coding agents in production, this is a maintenance cost worth planning for.
