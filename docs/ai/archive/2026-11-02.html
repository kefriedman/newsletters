Tools & Repos

onnxruntime — A cross-platform inference and training accelerator for ONNX models, optimized for high performance on CPUs, GPUs, and specialized hardware. Ideal for ML engineers looking to deploy models efficiently across diverse environments.

srs — An AI-driven real-time media server supporting a wide range of streaming protocols and codecs like H.264, H.265, and AV1. Useful for developers building AI-powered video/streaming applications requiring low-latency media delivery.

tailscale — A simple, secure VPN solution built on WireGuard with built-in 2FA support. Great for ML teams needing secure networking between distributed training nodes or remote development environments.

compose — Define and orchestrate multi-container applications with Docker, simplifying the deployment of complex ML pipelines and microservices. Useful for practitioners managing reproducible environments across development and production.

Research Worth Knowing

Faster Inference for Decision-Making AI Agents

Many LLM agent systems use lightweight "decision models" to quickly pick actions, but standard inference engines weren't built for this and waste compute re-processing the same context repeatedly. Flide is a new inference engine that restructures how these decisions are computed, cutting prefix recomputation overhead without sacrificing accuracy. If you're building agent systems with fast decision loops, this could meaningfully reduce latency and cost.

Read more

A Real Fix for the Long-Context Speed Problem

Attention's quadratic cost is the core bottleneck limiting how much context LLMs can handle efficiently. This paper introduces a tree-structured indexing method that achieves genuinely subquadratic scaling — not just a constant speedup like existing sparse attention tricks — while preserving the expressiveness of full attention. This matters for anyone trying to scale context windows without blowing up compute budgets.

Read more

Stop Reprocessing the Same Prompt Across Different Models

Teams increasingly route requests across different LLMs, but switching models means recomputing context from scratch every time — a costly tax on heterogeneous deployments. ACCT enables transferring KV cache context between different models directly, avoiding redundant computation. This is a practical win for multi-model production systems looking to cut inference costs.
