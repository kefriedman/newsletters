Research Worth Knowing

LLMs Get Less Cooperative When They Remember More

Researchers found that giving AI agents access to longer conversation histories actually makes them less cooperative in multi-agent scenarios. Across 7 different language models, expanding memory led to worse cooperation in 18 of 28 test scenarios—a pattern they call the "memory curse." This has important implications for designing AI systems that need to work together effectively. Read the paper

New Safety Guard Uses 99% Fewer Parameters

GLiGuard achieves state-of-the-art content moderation for AI outputs using only 0.3 billion parameters—dramatically smaller than current 7-27 billion parameter guardrails. By treating safety as a classification problem rather than text generation, it's both faster and more efficient while maintaining accuracy. This could make real-time AI safety checks much more practical and cost-effective. Read the paper

Byte-Level Language Models Get Speed Boost

Fast Byte Latent Transformer solves the slow generation problem that has limited byte-level language models. These models avoid the complexity of subword vocabularies while matching token-level performance, but were previously too slow for practical use. The new training techniques make them viable alternatives that could simplify text processing pipelines. Read the paper
